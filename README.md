# Jamshid Jalolov Portfolio

Premium one-page portfolio built with React, Vite, TypeScript, Tailwind CSS, Framer Motion, and Lucide React.

## Stack

- React
- Vite
- TypeScript
- Tailwind CSS
- Framer Motion
- Lucide React

## Install

PowerShell may block the direct `npm` shim on this machine, so use:

```powershell
cmd /c npm install
```

## Run

```powershell
cmd /c npm run dev
```

## Build

```powershell
cmd /c npm run build
```
